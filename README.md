# Шестая планета

Браузерная стратегия-симулятор колонии на чужой планете.

## Запуск

Откройте [главную страницу](index.html) или сразу [запустите игру](game.html).

## Сайт

Главная страница адаптирована для телефонов и компьютеров. На ней есть описание игры, основные особенности, встроенный видеоролик, галерея скриншотов с увеличением и поиск по журналу обновлений.

## Игра

В `game.html` находится сама игра. Файл игры не заменялся при обновлении сайта.
